# DEPLOYMENT: THE UPGRADE (deploy.txt)

### The Story: "The Software Update"
Now that we've pushed our "Senior Engineer" code to GitHub, we need to tell the VPS (your computer in the cloud) to go fetch the new instructions.

---

### Step 1: Entering the Building (SSH)
**Analogy: Walking into the VPS Office.**
Open your terminal on your computer and run:
`ssh username@your.vps.ip.address`

---

### Step 2: Grabbing the New Blueprint (Git Pull)
**Analogy: Fetching the latest mail.**
Once you are inside the `Mister_ReposterV2` folder on the VPS, run:
`git pull origin main`

This tells the VPS to check GitHub and download all the new "Skeleton" and "Nervous System" updates we just made.

---

### Step 3: Refreshing the Supplies (Pip)
**Analogy: Buying any new gear.**
Just in case we added new tools (like `uuid` or `aiofiles`), run:
`pip install -r requirements.txt`

---

### Step 4: Restarting the Machine (Screen)
**Analogy: Turning it off and on again.**
If you are using `screen` to keep the bot running while you sleep:
1. **Find the bot**: `screen -r bot` (assuming your screen is named 'bot')
2. **Stop the old bot**: Press `Ctrl + C`
3. **Start the new bot**: `python main.py`
4. **Walk away**: Press `Ctrl + A` then `D` (to detach)

---

### Senior Tip: THE "ONE-CLICK" DEPLOY (deploy.sh)
Tired of typing 4 commands? You can create a file called `deploy.sh` on your VPS:
```bash
#!/bin/bash
git pull origin main
pip install -r requirements.txt
# Kill the old process (if not using screen) or just restart manually
python main.py
```
Then you just run `./deploy.sh` and you're done!

---

### Summary for Non-Coders
To update your bot, you just need to "pull" the changes from GitHub to your VPS and restart the script. Because we implemented **Auto-recovery**, the bot will automatically remember every channel it was watching and resume its work immediately.
